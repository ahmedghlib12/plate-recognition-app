# 🚗 نظام كشف واستخراج لوحات السيارات

مشروع تخرج: اكتشاف لوحة السيارة واستخراج رقمها حتى مع الصور الضبابية أو المطينة أو المطموسة.

## المميزات
- اكتشاف موقع اللوحة تلقائياً وقصّها.
- 6 طرق لتحسين الصورة (تباين، حدة، عتبة تكيفية، إصلاح الطمس، إزالة البقع، عكس الألوان).
- قراءة بالعربية والإنجليزية عبر Tesseract وانتخاب أفضل نتيجة.
- تحليل اللوحة العراقية (رمز المحافظة - حرف - رقم).
- رفع صورة أو التقاطها بالكاميرا، وسجل نتائج قابل للتنزيل CSV.

## هيكل المشروع
```
app.py                الواجهة (Streamlit)
src/detector.py       اكتشاف اللوحة
src/preprocessing.py  تحسين الصورة
src/ocr.py            قراءة النص
src/parser.py         تحليل رقم اللوحة
tests/                اختبارات
packages.txt          حزم النظام (Tesseract) لـ Streamlit Cloud
requirements.txt      مكتبات بايثون
```

## التشغيل محلياً
1. ثبّت Tesseract (ويندوز: نسخة UB-Mannheim مع اللغة العربية). لينكس: `sudo apt install tesseract-ocr tesseract-ocr-ara`
2. `pip install -r requirements.txt`
3. `streamlit run app.py`
4. الاختبارات: `pytest`

## النشر على Streamlit Cloud
1. ارفع كل الملفات إلى GitHub (يجب أن يكون `packages.txt` في المجلد الرئيسي).
2. من share.streamlit.io اختر المستودع وملف `app.py`.
3. عند أي تعديل: Manage app ← Reboot.

## نصائح للدقة
- صوّر اللوحة من الأمام وبإضاءة جيدة.
- فعّل "عرض تفاصيل المعالجة" لمعرفة أي طريقة نجحت.
